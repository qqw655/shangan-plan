# 上岸计划

117 天广东省考模块化备考计划 App，按学习科学（测试效应、间隔重复、交错练习）设计，每天告诉你每个模块学多久、学什么，做完打勾打卡。

## 功能

- **今日模块**：自动按距考试天数切换四个阶段（打底期 → 巩固期 → 套题期 → 冲刺期），每个模块有每日时长和学习内容
- **打卡**：完成一个模块点一下勾，进度条实时显示，连续天数自动记录
- **计划总览**：四阶段完整安排，随时查看每个阶段学什么
- **做题顺序**：计划页内置行测 90 题/90 分钟的推荐做题顺序（资料先行 → 数量殿后），含每模块时间预算
- **周测分析**：每周做完一套全真计时套卷后，把各模块"答对/共题"填进"周测"页，自动分析本周侧重（精确到题型）+ 每日 8 小时安排 + 时间策略；历史周测正确率趋势可见，今日页顶部显示本周主攻模块
- **策略页**：广东行测特点 + "着重练这些 / 果断放弃这些"（按广东卷特色和你的周测情况定制，如资料分析冲刺90%、数推套路补强、常识只跟时政、放弃数学运算难题和大作文）+ 每日三科时间分配 + 申论全权规划（广东不考大作文，只练概括/分析/对策/公文，踩点给分）
- **三科时间**：每日 8 小时已按 行测（主攻+辅助）· 公专（时间块，方法自定）· 申论（全权规划）分配进四个阶段
- **考试日期**：可修改（默认 2026-12-05），倒计时自动更新
- **备份**：打卡与周测数据可导出 / 导入，换手机不丢

## 阶段速览

| 阶段 | 天数 | 重点 |
|---|---|---|
| 打底期 | 第 1-30 天 | 行测模块打底 + 公专框架 + 薄弱专项，每日约 8.4 小时 |
| 巩固期 | 第 31-75 天 | 模块提速 + 公专真题 + 申论上手 + 科学推理 |
| 套题期 | 第 76-105 天 | 全真模拟为主，公专套题 + 申论强化 |
| 冲刺期 | 第 106-117 天 | 减量保状态，只复盘不学新 |

## 怎么装到 iPhone 桌面

本应用已部署在 GitHub Pages 永久地址：

- 上岸计划：https://qqw655.github.io/shangan-plan/

1. 用手机 Safari 打开上面的网址（https 开头）
2. 点"分享" → "添加到主屏幕"
3. 桌面出现"上岸计划"图标（一本藏蓝底的书），点开即可全屏使用，断网也能用

## 更新

更新内容后重新推送 GitHub（`shangan-plan` 仓库），网址不变；手机 Safari 重新打开即可。数据存在手机本地，不会丢。

## 文献依据

- 测试效应 / 主动回忆：Roediger & Karpicke 2006；Dunlosky 等 2013
- 间隔重复：Cepeda 等 2006
- 交错练习：Rohrer & Taylor 2007
- 刻意练习：Ericsson
- 睡眠与记忆：Walker

## 申论规划（全权负责）

广东县级申论只考小题（概括/分析/对策/应用文），不考大作文：
- 打底期 W1-30：每周 2-3 题单一概括题，学"踩点"（圈关键词→同类合并→规范表达）
- 巩固期 W31-75：每周 1 套真题小题（综合概括+分析+对策），公文按 通知/倡议书/讲话稿/工作建议 每周 1 种
- 套题期 W76-105：每周 2 套广东真题限时 90 分钟，逐题踩点复盘
- 冲刺期 W106-117：只回顾踩点技巧+公文格式+高频规范词，每 3 天练 1 题
